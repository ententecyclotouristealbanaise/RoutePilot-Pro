Ce dossier est destine a l'archivage des tournees exportees en JSON.

Dans l'application RoutePilot Pro:
1. Ouvrez "Dossier tournees"
2. Cliquez sur "Choisir un dossier"
3. Selectionnez ce dossier "tournees"

Ensuite, chaque sauvegarde de tournee peut aussi etre ecrite ici (si le navigateur autorise l'acces au systeme de fichiers).
